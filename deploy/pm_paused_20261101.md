# Polymarket paused (2026-11-01)

roc paused all Polymarket work on 2026-11-01 20:13 SGT: every research direction,
the server-side observer / paper maker, and its scheduled monitoring.

## What is off

- `polymarket-observer` compose service is behind the opt-in `polymarket` profile in
  `docker-compose.yml` and `docker-compose.ghcr.yml`, so a normal `docker compose up -d`
  no longer creates or starts it. The observer is the only process that runs the
  Polymarket WS feed, recorder and paper maker.
- The scheduler keeps `POLYMARKET_OBSERVER_IN_SCHEDULER=false` (unchanged), so no
  shared container hosts the observer. Celery beat has no Polymarket entries.
- Host monitoring units on qd-sg were stopped and disabled:
  `pm-ss-sampler.service`, `p51-srv.service`.

Strategy code, data tables and paper account history are kept as-is.
Futu / HK / US paper trading is not affected.

## Restore

```bash
docker compose -f docker-compose.yml -f docker-compose.futu-paper.yml \
  -f docker-compose.futu-paper.images.yml --profile polymarket up -d --no-deps polymarket-observer
sudo systemctl enable --now pm-ss-sampler.service p51-srv.service   # optional monitoring
```

Set `FUTU_BACKEND_IMAGE_REF` inline for the command. To make it permanent, remove the
`profiles: ["polymarket"]` line.
