# HK Agent 按标的参数（P0 item 0）

沿用 `price_trigger` 单标的任务与富途 HK SIMULATE 执行链路。在 Agent
工作区选择港股价格任务后，可刷新生效参数、暂停后保存参数及翻页查看逐字段审计。
新增小米 `01810.HK` 任务自动采用本工作包默认值，模式为 `plan_only`。
已有任务不会被静默改写：界面标记默认值尚未应用，保存后才应用。
其他港股必须填写已知每手股数；执行时重新获取券商整手数据，不匹配拒绝下单。

默认：本金 100000 HKD，单笔 20000，每日买入 40000，储备 20%，最大持仓
60000；昨收 ±2% 或 5 分钟 ±1%，同向冷却 30 分钟，每日最多 8 次；
开盘竞价、午休与收盘前 5 分钟禁入；止损 5%，每日亏损为本金 2%，回撤 8%；
模型 `deepseek-v4-1-flash`，已知小米每手 200 股。模型必须在任务所选服务商的
配置目录中可用，保存时验证；新任务默认模型不可用时，就绪检查/执行失败关闭，
不会跨服务商降级。未指定服务商的新任务使用 DeepSeek。

触发为新鲜推送的阈值边沿；短窗需要先积累完整窗口，缺失昨收不会伪造数据。
冷却按方向分别记录，每日按香港时区重置，假日、半日市遵循交易日历。
竞价/午休参数不能覆盖券商连续交易时段门禁，关闭开关也不会授权这些时段下单。
每日买入限额按香港日期预占买单请求金额，包含不明确状态；取消/失败保守保留额度。
账户层每日总成交/委托额度仍可更严格，包括卖单，不被本参数覆盖。

回撤触发暂停并保留仓位供人工检查；需在暂停任务上手动重置保护后才能恢复。
本金开始绩效跟踪后不可修改。已有未完成订单时拒绝编辑。保存与审计、任务版本、
内部 actor 限额和旧运行取消在同一事务提交；不修改账户授权或操作员门禁。

迁移使用 `python -m app.commands.migrate`，新增
`20261012_agent_symbol_config.sql`。参数表 `qd_agent_symbol_configs` 以任务/标的
为键，审计表 `qd_agent_symbol_config_audit` 记录用户、时间、字段、旧值、新值。
运行参数原子物化到已有任务 `config`，调度、保护和执行读取相同版本。

认证 API：

- `GET /api/agent-automations/{id}/symbol-config`：参数、生效任务配置、版本、状态。
- `PUT /api/agent-automations/{id}/symbol-config`：完整参数对象，百分比使用 2 表示 2%。
- `GET /api/agent-automations/{id}/symbol-config/audit?before={audit_id}`：每页 100 条，按 ID 倒序。

本工作包仅本地 PG18、stub 券商与前端验证，不连接 OpenD、不调用真实模型、不下单。
真实 SIMULATE 联调与后续 P0 工作项不在本次范围内。
