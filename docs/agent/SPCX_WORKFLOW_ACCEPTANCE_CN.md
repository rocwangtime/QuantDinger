# SPCX Agent 工作流验收（2026-10-03）

## 范围

在新加坡部署环境通过浏览器实际调用已配置的火山方舟模型，以 SPCX 美股分别体验机会研究、固定规则策略开发、保存和回测，以及按条件重复研究。仅创建研究任务和策略草稿；未启用定时任务、账户自动交易或服务器交易硬开关，未向券商下单。

## 实际结果

| 路径 | 验收结果 |
| --- | --- |
| AI 投研 → 下一交易日机会 | 实际生成买入、退出、观望的条件式报告，识别周末和下一交易日，不伪造统计胜率；显示模型、Token 和估算费用。 |
| 明确要求开发策略 → 生成代码 | 生成平台原生 `initialize/handle_data` 策略，代码校验通过；长仓 5/20 日均线交叉，10% 仓位上限，5% 原生止损，不加杠杆。 |
| 回答 → 保存 → 回测 | 无须复制代码。新生成策略可直接导入工作台；已打开工作台时也会刷新并选中正确的新策略，不回退到旧代码。 |
| 短历史回测失败 | 默认过早起始日导致预热不足，页面持续展示具体原因；不会只闪现提示后留下空页面。 |
| 合理历史窗口回测 | 2026-07-20 至 2026-10-02，初始资金 10,000，手续费/滑点各 0.05%，1 倍杠杆：2 笔成交、1 次完整交易，止损触发，最终权益约 9,950.04，收益约 -0.50%，交易账本校验通过。 |
| 回答 → 持续研究任务 | 保存完整研究目标、时间窗口、间隔和事件条件；新任务默认暂停，支持编辑和确认后单次执行。 |
| 按自定义研究条件单次执行 | 5/20 均线上穿及放量条件进入模型上下文，能区分已满足、未满足和未知；最终报告为 HOLD，并说明估值、基本面及位置风险，未自动下单。 |
| 周末的常规交易时段门禁 | 单次执行记录为 skipped / Outside regular trading session，不调用模型。 |
| 价格事件遇到过期行情 | 周末旧的 1 分钟 K 线不能触发，记录为 skipped / No fresh closed 1-minute candle for price trigger，不调用模型。 |
| 模型结构化输出无效 | 返回 failed 并展示原因，不再用兜底 HOLD 冒充成功报告；本轮首条失败验收记录已纠正状态并保留原始输出。 |

回测结果仅证明流程和止损执行可用，不证明策略盈利。SPCX 历史较短，未满足的长周期指标应标记缺失；本次 SPY 基准数据不可用，已在回测中披露。

## 本轮修复

- 股票提示词不再混入永续合约、资金费率和 24 小时交易的默认假设。
- 研究任务的自定义条件真正进入模型请求，失败输出不会被计为成功分析。
- 增加前后两个交易日的均线值和交叉证据，防止仅凭均线当前大小猜测刚刚交叉。
- 美股、港股日线按交易所日历及收盘延迟判断完成状态，不按固定 24 小时猜测；删除“最新 K 线可能未收盘”的无条件断言。
- 后端计算均量、放量倍数、实际量阈值，以及下一根 K 线对应的滚动阈值，避免将均量误当作 1.2 倍触发量；不足 20 根有效历史成交量时不确认量比。
- 生成回答提供真实的策略保存/回测及持续研究入口，费用展示覆盖策略生成失败路径。
- 保留 BUY 和 SELL 研究线索；SELL 表示退出风险，不等于允许股票做空。

## 两种模式的使用方式

1. **固定规则策略**：AI 投研写清标的、周期、进出场与风险限制 → 生成可回测策略 → 保存并回测 → 核对成交和样本外表现 → 另行确认模拟执行授权。
2. **持续机会研究**：AI 投研形成分析框架 → 持续跟踪此结论 → 在任务中心设置时间窗口/间隔/价格事件并检查研究目标 → 先单次执行查看记录，再决定是否启用。

持续研究并不是永远在后台运行的自主交易循环。它按窗口/事件读取新数据后调用模型；定时研究、交易计划、账户授权和自动执行是不同状态。报告中的建议不等于已下单。

## 未声称通过的范围

- 本轮没有进行新一轮券商模拟买卖或长时间无人值守运行；账户交易门禁仍保持关闭。
- 当前只实测定时、交易时段和价格门槛触发，不能据此宣称新闻、财报等任意事件驱动都已验收。
- 新闻检索和部分公司基本面证据不可用，报告必须如实提示；模型的自由文本判断仍须复核。
- 没有验证预测第二天涨跌的准确性；提供的是带证据和失效条件的情景计划，不是确定性收益承诺。
