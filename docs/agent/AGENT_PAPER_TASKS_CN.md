# Agent 模拟组合任务

从侧栏进入 **Agent 模拟组合**（`/#/agent-tasks`）。先在账户页添加富途
US/HK 模拟账户，再新建每日组合评估或单股价格触发任务。

1. 填写投资任务、股票范围、本金、现金比例和交易限额，选择已配置模型。
2. 保存后 **预览决策**，检查依据、失效条件和本次账户/行情证据。
   预览会调用模型，但不会执行订单。
3. 自动模拟下单需要先在账户页启用有效自动交易授权，再启动任务。
4. 同页查看持仓、订单回执、决策、模型费用估算和逐步积累的收益曲线。

独立持仓保护由程序检查，不需要等待模型再次判断。单股止损锁定该股票的
新增买入；组合当日亏损或回撤阈值锁定组合买入，并尝试减仓。退出同样受
账户授权、交易限额、整手要求和新鲜报价约束。授权失效或订单状态不明等
受阻原因保存在运行记录里。这不是券商端保证成交的止损单。

暂停后停止提交并申请撤销挂单，已有持仓保留。券商已接受的订单仍可能在
撤单确认前成交，系统继续对账。保护不会随价格恢复自动解除；暂停后可显式
重置。重置保留收益历史，并以最近有效净值重设当日亏损和回撤保护基准。
仍低于成本止损线的持仓会再次触发。

收益只计算任务所属实际累计成交，排除账户其他资产。接管持仓以接管市值
作为任务成本，并占用本金。税费、分红及利息暂未计入。缺成交均价、初始估值
或持仓对不上时，完整收益率不可用；界面保留最近有效估值及时间。旧任务
不会补造历史价格。跟踪开始后本金不可修改。

基准是初始股票范围等权买入持有，加上初始现金比例，允许理论碎股。从首次
同时取得全部有效报价开始，起点单独显示；修改股票范围不会重写基准。
此版本不提供历史 Agent 回测、年化收益或胜率。

费用为完整决策的模型价格估算，包含预览，不包含失败/取消调用及券商费用。
不同货币分别累计，未知模型价格不会记为免费。

部署需更新后端与独立 Vue 客户端。后端自动应用
`20261006_agent_performance.sql`，调度器承担持续监测。禁用自动迁移的部署
需先应用迁移。旧任务保护保持关闭，需要暂停后编辑启用。

实现与限制见 [设计说明](../architecture/AGENT_PAPER_DASHBOARD.md)。

## 受限研究与盘中组合复核

新建任务默认选择「受限工具研究循环」，已有任务保留「单次快照判断」。
在「触发方式」选择「盘中组合复核」，设置相对上次复核的价格变化幅度、
成交后复核和冷却时间，先预览决策，再启动任务。

首次有效观测会请求一次复核。之后，在价格达到变化幅度或本任务累计成交变化时
请求新复核。每 30 秒采样可能错过两次观测之间的波动；已有分析、挂单、
缺失证据或风控锁定会推迟复核。盘中事件有效期为三分钟，超时决策不能延迟下单。
独立持仓保护优先处理，仍然不调用模型。

研究循环只开放账户、行情、已完成日线的本次快照，以及按需新闻搜索。
当前采用应用层校验的 JSON 工具协议，复用可取消的模型流式调用；
并非提供商原生 function calling。模型可以先申请查询允许股票的日线、阅读结果，
再输出买入、减仓、退出、持有或等待。它没有任意券商指令、URL、脚本或 SQL 工具。
最终订单仍由程序刷新账户和行情并校验。15 秒快速价格触发保持单次快照判断。

| 配置 | 默认值 | 说明 |
|---|---|---|
| `research.mode` | 后端及旧任务 `snapshot` | 新建每日/盘中任务界面默认 `tool_loop` |
| `research.max_model_calls` | 3 | 每次任务最多 1–4 轮，最后一轮必须给出完整决策 |
| `research.max_tool_requests` | 6 | 每次任务最多 1–8 次资料查询，每轮最多两次 |
| `research.max_output_tokens` | 7000 | 各轮累计输出 token 上限，范围 700–14000 |
| `research.max_decisions_per_day` | 8 | 每个交易所本地自然日创建的任务额度，范围 1–100 |
| `events.price_move_pct` | 0.02 | 相对上次已受理复核的绝对价格变化；界面显示 2%，范围 0.1%–50% |
| `events.on_fill` | true | 本任务累计成交变化后复核 |

每日额度在任务创建时预占，预览、失败和取消也计入；编辑或重启不清空已消耗额度。
额度按市场时区午夜重置，包含夏令时处理。程序保护不占模型决策额度。
调用次数和输出 token 限制不等同于金额预算，输入 token、推理和提供商计费仍可能增加费用。
不完整、格式错误、超预算或被取消的输出都不能执行。

工具循环逐轮记录调用及能获取的失败/取消用量；提供商没返回总量时使用文本估算。
失败的单次快照调用仍未纳入用量覆盖，新闻服务费和券商费用也不在模型费用估算内。
页面展示额度和重置时间、复核原因、模型/资料查询次数，详情可查看每次查询结果。
「决策复盘」只统计最近 30 次任务的建议决策，并区分预览和程序保护；
实际模拟表现仍以订单回执和后续毛收益曲线为准，不据此推断胜率。


## 运行检查与连续模拟验收

任务页新增「运行检查」。打开页面只读取配置和已记录状态，不会调用模型或券商。
界面分别显示模型、任务内部执行范围、账户授权、股票范围、操作者启用状态、
决策额度、账户交易额度、Agent 心跳及持仓保护。模型配置检查只确认所选提供商
与配置可用，不代表已经连通模型服务。当前任务支持 OpenAI、DeepSeek 和火山引擎。
缺少配置会在启动前拦截；暂停仍可操作。

点击「检查富途连接（只读）」才会访问所选 SIMULATE 账户，验证账户与市场，
并在交易时段检查候选股票的可执行行情。休市显示等待；错误只显示经过清理的
状态。结果最多保留 90 秒，仅对当前任务版本有效；修改配置后需重新检查。
这些结果不授予下单权限，每次实际模拟订单仍刷新账户、报价并执行全部授权校验。

独立 `scheduler` 进程将 Agent 组件心跳写入现有调度心跳。旧进程没有组件信息时
显示「未验证」，不能据此认定健康。连续失败与心跳停滞分别显示降级或过期。
需要更新并重启调度进程才能发布新状态。进程内停止再启动时，旧模型调用与
旧执行回调会因运行代次变化失效；重新受理的持久化计划仍需当前授权与行情。

「模拟运行报告」可选择最近 7、14、30、90 天，展示按市场时区汇总的观测日期，
并下载 JSON。时间窗口是滚动时间范围，表格时间按报告标明的市场时区显示。
报告包含运行状态、建议动作、预览/程序保护、模型用量、当前风控和本任务累计成交。
只读取数据库记录，不触发券商对账或新决策。

- 当日变化指首次与最后有效估值之间的变化，不是完整交易日收益；单点留空。
- 最多读取最近 1000 次运行、10000 次估值、1000 条更新订单；达到上限标记部分报告。
- 订单按更新时间筛选，成交是当前累计值，不推断逐笔成交时间。
- 最近有效任务表现与当前风控是整体最新状态，不限于报告时间窗口。
- 模型用量保留覆盖范围及未知价格，净值仍未扣除税费、分红和利息。

多日模拟验收时，每个交易日前检查模型与富途连接，确认股票范围、交易限额和
保护阈值；先预览，再由操作者启用账户与任务。账户自动交易授权最多 24 小时，
到期需人工重新授权，任务不会自动续期。连续运行后导出报告，核对成交回执、
毛收益、基准、保护动作和模型费用。只有完成真实运行环境的模型/OpenD 联调和
多个交易日的观测，才算运行验收；本地合成数据测试不证明盈利。

接口与验收设计见 [运行验收说明](../architecture/AGENT_RUN_ACCEPTANCE.md)。
